# 表格汇 TableHub

> **让所有表格，都能被快速找到。**
>
> 把分散的表格和方案集中管理，让你搜索名字就能快速找到需要的内容。

一个可点击体验的完整 AI SaaS 前端 Demo：**汇集 + 搜索 + AI 整理 + 防止发错**。

---

## 快速开始

```bash
# 1. 安装依赖（本机 Node 不在 PATH 上时，用绝对路径调用）
pnpm install

# 2. 开发模式（带 HMR）
pnpm dev            # http://localhost:5180

# 3. 生产构建 + 本地预览
pnpm build          # 输出到 dist/
pnpm serve          # 等价于下面这行，端口 5180
python serve.py 5180
```

打开 <http://127.0.0.1:5180/> 即可。

> **最省事的方式**：双击 `启动表格汇.bat`，会自动打开浏览器并启动服务（关闭窗口即停止）。

> **端口被占用时会自动顺延**：`serve.py` 从 5180 开始尝试，最多 +9，并把实际地址打印出来（`python serve.py 5180 --open` 可在绑定成功后自动打开浏览器）。Windows 下已关闭 `SO_REUSEADDR`，否则端口冲突会被静默掩盖成"启动成功但收不到请求"。

> `dist/` 使用相对路径 + HashRouter 构建，所以**直接双击 `dist/index.html` 也能打开**（无需服务器）。

## 核心体验

### 1. 超级搜索（真实可用）

搜索不是假交互：`src/lib/search.ts` 里有完整的相关度打分引擎。

- 归一化查询（自动剔除「帮我找」「最近的」等噪声词）
- 打分维度：文件名完全匹配 200 / 包含 120 / 客户 40 / 标签 28 / 分类 24 / 关键词 20 / 负责人 18 + 时效加成
- 支持按类型、客户、标签、收藏筛选与四种排序
- 输入时实时联想（文件名 / 客户 / 标签 / 员工），支持 ↑↓ 选择、Enter 打开

试试搜索：`星河科技`、`报价表`、`员工报销`、`V3`。

### 2. AI 搜索助手

搜索结果顶部由 AI 生成结论：命中数量与类型分布、最相关的两份文件、**建议发送的那一份**（含最后更新时间），并提供「打开文件」直达。

### 3. 防止发错方案

同一系列文件（如 `星河科技合作方案 V1/V2/V3`）带 `seriesId`。点击 **分享** 会触发 AI 版本检查：

- 发现更新版本 → ⚠️ 提示「当前文件 / 系统发现 / 更新时间 / AI 建议」，可选 **使用最新版本** 或 **仍然发送当前文件**
- 已是最新 → ✅ 「这是最新版本，可以放心发送」

演示路径：详情页打开 `星河科技合作方案 V2.docx` → 点「分享」。

### 4. AI 自动识别与上传

表格汇集器（`/collector`）支持真实文件选择与拖拽，也提供「体验 Demo 上传」一键跑完整流程：

上传进度 → **AI 识别文件内容** → 汇总「共处理 N 个文件 / 发现 X 个表格 / Y 个 PPT / Z 个 PDF」→ 逐条展示识别出的客户、类型、关键词、标签与置信度 → 真正写入文件库，立即可被搜索到。

### 5. AI 创建客户方案

方案中心 → **✨ AI 创建方案**：选择客户、方案主题、勾选参考表格 → 四步生成动画 → 方案预览（项目背景/服务内容/合作方式/项目报价/时间安排）→ 导出 PPT（下载 HTML 讲稿）或保存到方案中心。

### 6. AI 助手对话

规则 + 数据推理，覆盖需求文档里的两个示例问题，并可继续追问：

- 「帮我找星河科技最近的报价表」→ 命中文件 + 最新更新 + 是否打开
- 「哪些客户最近没有更新方案？」→ 按最后更新排序，给出需重点跟进的客户
- 「本月员工报销一共多少钱？」→ 汇总金额、待审核笔数、金额 Top3
- 「有没有发错版本的风险？」→ 列出所有多版本系列及最新版本

## 已知限制

- 纯前端 Demo：没有后端与真实 AI API，所有「AI」能力由 `src/lib/search.ts` 与 `src/lib/ai.ts` 的规则推理模拟，**不联网也能完整演示**
- 上传、下载、分享都是前端模拟（下载会生成一个说明用的文本文件；导出方案会生成可打印的 HTML 讲稿）
- 文件预览是 Demo 生成的示例数据，未接入 Office 在线预览
- 语音输入相关：本项目的搜索框是键盘输入；如果后续要接语音输入，可直接复用 `SearchBar` 的 `onChange/onSubmit`
